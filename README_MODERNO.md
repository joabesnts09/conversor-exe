## 📦 Instalação

### Opção 1: Instalação Automática
```bash
python3 install_modern.py
```

### Opção 2: Instalação Manual
```bash
pip install customtkinter --break-system-packages
```

## 🎯 Como Usar

### Launcher (Recomendado)
```bash
python3 launcher.py
```
- Escolha entre interface clássica ou moderna
- Interface amigável para seleção

### Interface Moderna Direta
```bash
python3 conversor_gui_moderno.py
```

### Interface Clássica
```bash
python3 conversor_gui.py
```

## 🐛 Solução de Problemas

### ❌ Erro: "CustomTkinter não encontrado"
```bash
pip install customtkinter --break-system-packages
```

### ❌ Erro: "Interface não inicia"
```bash
python3 install_modern.py
```

### ❌ Erro: "Dependências faltando"
```bash
pip install -r requirements.txt --break-system-packages
```

## 📞 Suporte

### 🆘 Problemas Comuns
1. **Interface não carrega**: Verifique se CustomTkinter está instalado
2. **Animações lentas**: Reduza a frequência de atualização
3. **Cores estranhas**: Verifique o tema do sistema

### 💡 Dicas de Uso
- Use o launcher para alternar entre interfaces
- A interface moderna é mais pesada, mas oferece melhor experiência
- Para melhor performance, use a interface clássica em sistemas antigos
